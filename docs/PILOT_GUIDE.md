# Using the private pilot

Open the local workspace at http://127.0.0.1:4317. Choose **All archived dates** to include the historical teaching examples. The computer must stay on for this local preview to remain available.

## Start with the source posts

**Dashboard** shows the topics and subtopics in the selected archive, alongside supporting posts. Select a subject to inspect its sources. Member counts refer to distinct represented members; one member's several posts do not become several members. Filters change the selection, so check the date range before interpreting a count.

**Explore** searches the available original wording. Open **View on X** when you want the public source. A saved caption can still be missing the linked article, quoted post, image or video; those limits appear with the source.

**Related subjects** searches ideas. For example, try “immigration detention release.” Results show the relevant passage and complete available post. Similar passages can express opposing positions, so read the surrounding wording before drawing a conclusion.

**Exact wording** finds the phrase as typed, including case and punctuation. The source remains complete, and overlapping matches are highlighted. **Emerging subjects** suggests groups of related passages. Empty results are expected when this small archive lacks enough qualifying sources. A group does not by itself establish agreement, coordination or a newly occurring event.

## Teach through a short voice session

Start voice chat in this Codex task and open **Teach**. The dashboard saves reviews; it does not record audio. Three real source cards are ready for a first session of about 15 minutes.

For each post:

1. Read the complete available wording, its date and context limits.
2. Inspect the proposed topics, narrower subjects and supporting excerpts.
3. Explain what the post is about and the words that justify that interpretation. Overlapping topics are allowed.
4. Save one of three decisions: supported topic labels, no supported topic, or more context needed. Give a short reason.

An accepted correction changes that post's displayed classification immediately. “More context needed” preserves the tentative labels in the review while keeping them out of topic counts and accepted teaching examples. A possible general lesson is saved separately for testing. If the source, proposal or prior review changed while you were reading, reload it before saving.

The local classifier currently uses fixed hypotheses. It does not retrain from this conversation or apply a newly proposed rule across the archive automatically. The next learning step is to collect varied judgments, reserve separate examples for evaluation, and compare a candidate model before promoting it. Your existing review remains available in its history.

## Review local incidents

Open **Incident desk** for suggested reports or use **Review incident / location** from any source in Teach. A named place requires supporting source wording. A member's district alone does not establish where the incident occurred. You can reject a suggestion, request more context, save a supported report, and organize related reports into a tracked case.

Case status is an explicit judgment. A quiet period does not resolve a case automatically. A copied case digest stays on the local clipboard until you choose to use it elsewhere.
