# Public news context

The dashboard and classifier use public reporting acquired through the source registry. See [NEWS_CONTEXT.md](NEWS_CONTEXT.md) for retrieval, provenance and freshness limits.

Private inbox inputs and mail-derived research are excluded from this public checkout and its generated site. The former mail-context snapshot and derived narrative exports have been removed from the current tree. This does not rewrite repository history.

A future private inbox worker must retain mailbox content and identifiers outside this repository. It may discover candidate public URLs, but publication requires independently fetching the public source; only that public source can supply displayed evidence.
